==============================================================================
  ZKTeco Attendance Downloader - DEPLOYMENT GUIDE
  (give this file to whoever is installing the app on each PC)
==============================================================================

WHAT THIS IS
------------
A single Windows program: ZKTecoAttendanceDownloader.exe
- Downloads attendance logs from a ZKTeco fingerprint/face device
- Exports to .dat and/or .xlsx files
- No Python, no installer, no admin rights needed on the target PC

------------------------------------------------------------------------
STEP 1 - GET THE .exe
------------------------------------------------------------------------
You should already have a file called:

    ZKTecoAttendanceDownloader.exe

If you don't have it, ask whoever built it for you. (It was built with
build_exe.bat on a developer machine and is about 80 MB.)

------------------------------------------------------------------------
STEP 2 - COPY IT TO EACH TARGET PC
------------------------------------------------------------------------
Pick whichever is easiest:

  - USB stick: drag the .exe onto the USB drive, plug it into the target
    PC, drag the .exe to Desktop or any folder.
  - Network share: put the .exe on \\server\Tools\, drag to the target PC.
  - Email/Teams/Slack: ZIP the .exe (right-click -> Send to ->
    Compressed folder) and send. Some mail systems block raw .exe
    attachments - zip it.
  - OneDrive/Google Drive: upload the .exe, share the link, download
    on the target PC.

Where you put it on the target PC doesn't matter - Desktop, a Tools
folder, anywhere. The .exe is self-contained and portable.

------------------------------------------------------------------------
STEP 3 - RUN IT ON THE TARGET PC
------------------------------------------------------------------------
1. Double-click ZKTecoAttendanceDownloader.exe

   FIRST-LAUNCH NOTES:
   - It takes 5-10 seconds to open the first time. This is normal -
     it unpacks to a temp folder. Later launches are fast.
   - If "Windows protected your PC" (SmartScreen) appears:
       click "More info"  ->  "Run anyway"
     (This is normal for unsigned .exe files. Not a security problem.)
   - If antivirus quarantines or deletes it:
       restore / allow it, then add an exception for this .exe.
     (PyInstaller .exe files commonly trigger false positives.)

2. In the window that opens:
   - Device IP : type the ZKTeco device's IP (e.g. 192.168.1.201)
   - Port      : 4370 (read-only, correct)
   - Password  : 0 (read-only, correct)
   - Start     : pick the start date (time is fixed at 00:00:00)
   - End       : pick the end date (time is fixed at 23:59:59)
   - Format    : Both (.dat + .xlsx) is fine
   - Output    : click Browse... to pick where files are saved

3. Click Download. Watch the Log panel at the bottom - it shows every
   step. If it ends with "DONE: Saved N of M records", it worked.

------------------------------------------------------------------------
NETWORK CHECK (do this if download fails)
------------------------------------------------------------------------
The target PC must be able to reach the device on TCP port 4370.

On the target PC, open PowerShell and run:

    Test-NetConnection -ComputerName <DEVICE_IP> -Port 4370

You want to see:

    TcpTestSucceeded : True

If it says False:
  - Confirm the PC is on the same network as the device (same LAN/VPN).
  - Ask IT to allow outbound TCP 4370 from this PC to the device.
  - Confirm the IP you typed is the device's actual IP.

------------------------------------------------------------------------
IF IT STILL DOESN'T WORK
------------------------------------------------------------------------
1. Look at the Log panel - the full error is preserved there in red.
2. Copy the red text and send it to whoever built the .exe.
3. Common causes:
   - Wrong device IP (most common)
   - PC not on the same network as the device
   - Firewall blocking port 4370
   - Device powered off or not responding

------------------------------------------------------------------------
OPTIONAL: MAKE IT FEEL LIKE AN INSTALLED APP
------------------------------------------------------------------------
1. Right-click ZKTecoAttendanceDownloader.exe -> Create shortcut
2. Move the shortcut to:
     %AppData%\Microsoft\Windows\Start Menu\Programs\
   (Type that path into the address bar of File Explorer to open it.)
3. It will now appear in the Windows Start menu.
4. Optional: right-click the shortcut -> Properties -> Change icon
   to give it a custom icon.

This is a shortcut, not an installation. The .exe itself stays wherever
you put it and remains fully portable.
